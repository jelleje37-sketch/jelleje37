# Pulsewell PMO Portfolio

Project Management Office portfolio for the Pulsewell initiative, organized by project lifecycle phases.

## Directory Structure

- **01-initiation** - Project charter, business case, stakeholder analysis
- **02-planning** - Project plans, schedules, resource allocation, risk registers
- **03-execution-monitoring** - Status reports, deliverables, issue logs, change requests
- **04-closing** - Lessons learned, project closure documentation, final reports
