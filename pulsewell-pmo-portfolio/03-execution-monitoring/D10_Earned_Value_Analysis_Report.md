## DOCUMENT OVERVIEW

This Earned Value Analysis (EVA) report evaluates project performance at Mid-Execution, specifically at Sprint 4 / Week 7, using the approved $41,900 budget baseline. The analysis compares planned performance against earned work and actual cost to assess schedule and cost efficiency for the PulseWell initiative.

**Assessment Point:** Sprint 4 / Week 7  
**Project Baseline Budget:** $41,900  
**Reporting Basis:** EVM method using cumulative project metrics  

---

## 1. EVM ASSUMPTIONS AND CALCULATION BASIS

### EVM Data Inputs
- Budget At Completion (BAC): $41,900
- Reporting Period: Week 7 / Sprint 4
- Planned Value (PV): value of work scheduled to be completed by this point
- Earned Value (EV): value of work actually completed by this point
- Actual Cost (AC): cost incurred to complete the work performed

### Standard EVM Formulas
- Cost Variance (CV) = EV - AC
- Schedule Variance (SV) = EV - PV
- Cost Performance Index (CPI) = EV / AC
- Schedule Performance Index (SPI) = EV / PV
- Estimate at Completion (EAC) = BAC / CPI
- Variance at Completion (VAC) = BAC - EAC

The project is currently incurring more cost than the value of work earned:
- CV = -$1,300, indicating cost overrun at this stage
- CPI = 0.93, indicating that for every $1.00 spent, only $0.93 of value has been earned

### 3.2 Schedule Performance
The project is behind the planned execution pace:
- SV = -$2,700, indicating the project has delivered less value than planned at this point
- SPI = 0.86, indicating the project is progressing at 86% of the planned rate

### 3.3 Forecast to Completion
- EAC = $45,054, which is $3,154 above the approved $41,900 cost baseline
- VAC = -$3,154, confirming a projected cost overrun at completion unless corrective action is taken

## 5. ROOT CAUSE ANALYSIS

The current EVM profile indicates that the project is simultaneously:
- spending more than planned relative to earned work
- completing less work than scheduled at this stage of execution

The most likely contributors are:
- delayed external dependency resolution (vendor integration and compliance approvals)
- design and architecture refinement extending beyond planned effort
- increased troubleshooting during build and validation early in the execution phase
- resource constraints on high-priority technical tasks affecting productivity

## 7. EVM INTERPRETATION AT MID-EXECUTION

At Sprint 4 / Week 7, the project is showing a negative performance trend relative to the approved plan. The schedule variance and cost variance indicate early execution pressure and signal the need for corrective controls before the project approaches the next major milestone or testing phase.

The current performance indicates that without intervention, the project may finish above the approved cost baseline and behind the original 14-week schedule. Immediate governance attention is recommended to recover productivity, protect critical path activities, and reduce schedule and cost slippage.

## 8. GOVERNANCE RECOMMENDATION

The PMO and sponsor should convene a focused recovery review to:
- confirm the critical path and recovery options
- approve additional resource allocation if necessary
